# К кому обратиться, если доступ выдан, а 403 остался

Тестовая инструкция вымышленной команды «Каталог» для хакатона. Чек-лист Авито описывает работу с наставником и доступы. Маршрут обращения ниже придуман для демо.

1. Сверь адрес стенда со ссылкой в задаче и убедись, что открыт рабочий тестовый профиль. Повтори проверку по ссылке из задачи.
2. Если 403 остался при статусе **«Доступ выдан»**, обратись к **владельцу Catalog Dev**. Если контакт владельца недоступен, обратись к наставнику команды. Новая заявка на тот же доступ в этом случае не нужна.
3. Укажи стенд, ссылку на задачу, примерное время ошибки и действие, на котором возникла 403. Добавь номер заявки, если доступ выдавали по заявке. Отправляй только данные, которые нужны для проверки. Пароли, токены и cookies в сообщение не включай.

Черновик сообщения:

> Привет! Проверяю исправление на Catalog Dev по задаче [ссылка]. Право на чтение подтверждено, но при [действие] в [время] получаю 403. Можешь проверить доступ для моего рабочего профиля?
