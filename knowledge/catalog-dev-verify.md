# Как проверить исправление на Catalog Dev

Тестовая инструкция вымышленной команды «Каталог» для хакатона. Playbook описывает PaaS и инструменты тестирования. Порядок проверки конкретной задачи ниже придуман для демо.

1. Открой первую задачу. Найди в ней ссылку на **Catalog Dev**, версию сборки или ветку и ожидаемый результат проверки. Если чего-то не хватает, уточни это у автора исправления или наставника.
2. Войди в рабочий тестовый профиль и открой ссылку из задачи. Сверь, что на стенде развёрнута нужная версия. Если версия отличается или неизвестна, сначала попроси автора подтвердить, где проверять исправление.
3. На тестовых данных повтори шаги из задачи и сравни фактический результат с ожидаемым. Оставь в задаче короткую запись: стенд, проверенная версия, результат и шаг, на котором возникло расхождение, если оно есть.

Если стенд возвращает 403, проверь состояние доступа. При отсутствии доступа используй [инструкцию по заявке](catalog-dev-access.md). Если доступ уже выдан, используй [инструкцию по ошибке 403](catalog-dev-403.md).
